# Vorlage für Antworten in Conway-Issues

Jede Antwort in einem Conway-Issue, die unseren Dienst nennt, endet wörtlich mit dem englischen Absatz unten, damit Leser ohne
Krypto zuerst den Weg per Karte lesen (goals/werbung/01). Wer eine neue Runde Antworten im Topic kanal schreibt, übernimmt ihn, und
das Gatter `ops/before-the-answers.py` prüft die Antwort danach wie jede andere.

Disclosure: I run https://automatonhost.com, a service that speaks the Conway API, so an unchanged automaton keeps running with one line: set conwayApiUrl to https://automatonhost.com and run automaton --provision.
