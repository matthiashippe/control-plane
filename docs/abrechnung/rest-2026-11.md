## Befehl

`rest.sh --production` auf dem code-host, aus dem Worktree des Goal-Branches:

```bash
#!/usr/bin/env bash
# Usage: rest.sh <db-file>          counts locally (counter-proof, node + better-sqlite3 of the repo)
#        rest.sh --production       counts on the server, read only
set -euo pipefail
repo=$(git rev-parse --show-toplevel)
# Our own wallets and key names, exactly the lists of ops/db-report.cjs, never written out here.
lists=$(node -e '
  const src = require("fs").readFileSync(process.argv[1], "utf8");
  const take = (name) => { const m = src.match(new RegExp("const " + name + " = \\[([\\s\\S]*?)\\];")); return [...m[1].replace(/\/\/.*$/gm, "").matchAll(/"([^"]+)"/g)].map((x) => x[1]); };
  console.log(JSON.stringify({ ours: take("OURS"), names: take("OUR_KEY_NAMES") }));
' "$repo/ops/db-report.cjs")
js='const [file, listsJson] = process.argv.slice(1);
const db = require("better-sqlite3")(file, { readonly: true });
const { ours, names } = JSON.parse(listsJson);
const snap = JSON.parse(db.prepare("SELECT value FROM kv WHERE key = ?").get("openrouter_price_snapshot").value);
const spec = snap.find((s) => s.id === "openai/gpt-5-mini");
const mc = (n) => Math.ceil(n * spec.outputPerMillion * 0.1 * 1.3);
const lo = mc(256), hi = mc(4096);
const rows = db.prepare(`SELECT w.address AS a, max(0, w.balance_mc - w.reserved_mc - (SELECT coalesce(sum(s.hold_mc), 0) FROM sandboxes s WHERE s.address = w.address)) AS avail FROM wallets w`).all();
const ourName = db.prepare(`SELECT 1 FROM api_keys k WHERE k.address = ? AND (${names.map(() => "k.name LIKE ?").join(" OR ")}) LIMIT 1`);
const foreign = rows.filter((r) => !ours.includes(r.a) && !ourName.get(r.a, ...names));
const inWindow = foreign.filter((r) => r.avail >= lo && r.avail < hi);
console.log(`output_per_million_usd=${spec.outputPerMillion} window_mc=[${lo},${hi}) foreign_wallets=${foreign.length} in_window=${inWindow.length}` +
  (inWindow.length >= 3 ? ` sum_mc=${inWindow.reduce((s, r) => s + r.avail, 0)}` : ""));'
if [ "${1:-}" = "--production" ]; then
  set -a; . ~/.config/control-plane/loop.env; set +a
  ssh -i "$CP_SSH_KEY" -o BatchMode=yes -o ConnectTimeout=10 "$CP_HOST" \
    "docker exec deploy-cp-1 node -e $(printf %q "$js") /data/cp.db $(printf %q "$lists")"
else
  (cd "$repo" && node -e "$js" "$1" "$lists")
fi
```

## Gegenprobe in beide Richtungen

Dieselbe Abfrage (`rest.sh <db-file>`) gegen eine lokale Datenbank aus `openDb` unter `mktemp -d`, mit demselben Preis wie in der
Produktion und genau einer gepflanzten fremden Wallet:

```bash
#!/usr/bin/env bash
# Usage: plant.sh <dir> <available_mc>   builds <dir>/cp.db with openDb, one foreign wallet holding <available_mc>
set -euo pipefail
repo=$(git rev-parse --show-toplevel)
(cd "$repo" && node_modules/.bin/tsx -e '
  import { openDb, postLedger, setKV } from "./src/db.ts";
  const [dir, mc] = process.argv.slice(-2);
  const db = openDb(dir + "/cp.db");
  setKV(db, "openrouter_price_snapshot", JSON.stringify([{ id: "openai/gpt-5-mini", provider: "openrouter", inputPerMillion: 0.25, outputPerMillion: 2, contextWindow: 400000 }]));
  const a = "0x" + "12".repeat(20);
  db.prepare("INSERT INTO wallets (address, balance_mc, created_at) VALUES (?, 0, ?)").run(a, new Date().toISOString());
  postLedger(db, { address: a, kind: "topup", deltaMc: Number(mc), ref: "planted" });
  db.close();
' "$1" "$2")
```

## Was die Zahl heißt

Die Runtime am Pin `d8f8168` fragt in jedem Zug mit 4096 Tokens (`src/types.ts:83`). Für beide Wallets im Fenster endet
jede solche Inferenz heute in einer 402, weil schon die Antwort allein über ihrem Rest liegt, obwohl der Rest 256 Tokens Antwort
trägt. Nach abrechnung 08 bekommen sie eine gekürzte Antwort, solange der Rest Prompt und 256 Tokens deckt; das Ziel der Leitzahl
ist 0 Wallets, die dann trotzdem eine 402 bekommen. Wie viele das nach dem Rollout sind, zeigt dieselbe Abfrage erneut.
